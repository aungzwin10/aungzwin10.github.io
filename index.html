About

I like the boring parts.

I started as a programmer in Mandalay in 2017, implementing electronic medical records for Myanmar hospitals — which mostly meant sitting with nurses and finding out why the software everyone had specified wasn't the software anyone could use.

That never really stopped being the job. I've since built an attendance system for Japan, an integrated database for Southeast Asia, an ERP in Perl, and the Spring Boot APIs behind a suite of clinical apps. Those apps now run in more than forty hospitals across Myanmar, Cambodia, India, Pakistan and the Philippines. I manage the whole portfolio — eleven products — and still write the backend, because I don't trust an architecture I haven't had to debug.

Healthcare software has taught me one thing above everything: correctness beats cleverness. A feature nobody can find is a feature that doesn't exist. A migration that half-works is worse than no migration. I'd rather ship the plain version that holds.
